## 1. Use the Weyl-friendly critical coordinate

Set

\[
\boxed{
s=\frac12-iz.
}
\]

For a prime \(p\), define

\[
\boxed{
q_p(z)
=
p^{-s}
=
p^{-1/2+iz}.
}
\]

If

\[
z=x+iy,
\qquad
y>0,
\]

then

\[
|q_p(z)|
=
p^{-1/2-y}
<1.
\]

Therefore

\[
\boxed{
q_p:\mathbb C_+\to\mathbb D
}
\]

is a scalar Schur function for every prime.

This is unconditional and uses no zero information.

## 2. Local Euler factor is generated by a Schur variable

The local Euler factor is

\[
L_p(s)
=
\frac1{1-p^{-s}}
=
\frac1{1-q_p(z)}.
\]

Thus the same local quantity that generates the Euler factor is already a disk-valued analytic transfer variable throughout the entire Weyl half-plane.

Prime-power depth is simply iteration:

\[
\boxed{
q_p(z)^k
=
p^{-k/2}
e^{ikz\log p}.
}
\]

For real \(z=t\), this is exactly the critical half-density prime-power phase

\[
p^{-k/2}e^{ikt\log p}.
\]

So the Suzuki/Euler prime-power amplitudes are powers of one local Schur coordinate.

## 3. Cayley transform gives the local prime Weyl response

Define

\[
\boxed{
F_p(z)
=
\frac{1+q_p(z)}

\[
