# FUCC with SUCC: compositions, polynomial programs, and carry

**Date:** 2026-10-06  
**Status:** exact elementary algebra/combinatorics + a new carry-machine interface. RH remains open.

This note formalizes the observation:

> "Integer partitions/compositions are the number of ways you can FUCC with SUCC."

The exact statement uses **ordered compositions**, not unordered partitions.

---

## 1. Causal SUCC histories are compositions

Take \(n\) bare successor pulses:

\[
S\,S\,\cdots\,S
\qquad(n\text{ copies}).
\]

There are \(n-1\) gaps between adjacent pulses.

At each gap choose either:

- do nothing: remain in the same SUCC run;
- insert one FUCC boundary.

Thus every subset of the \(n-1\) gaps determines an ordered composition

\[
\alpha=(a_0,a_1,\ldots,a_k),
\qquad
a_i\ge1,
\qquad
\sum_{i=0}^k a_i=n.
\]

Conversely every ordered composition determines its set of cut positions.

Therefore:

\[
\boxed{
\{\text{causal FUCC/SUCC segmentation histories of }n\}
\cong
\{\text{compositions }\alpha\models n\}.
}
\]

If exactly \(k\) FUCC boundaries are inserted, there are \(k+1\) SUCC runs, so

\[
\boxed{
\#\{\alpha\models n:\ell(\alpha)=k+1\}
=
\binom{n-1}{k}.
}
\]

Summing over \(k\):

\[
\boxed{
\#\{\alpha\models n\}
=
2^{n-1}.
}
\]

Equivalently the FUCC-count generating polynomial is

\[
\boxed{
\sum_{\alpha\models n}
y^{\ell(\alpha)-1}
=
(1+y)^{n-1}.
}
\]

This is why Pascal appears: the \(k\)-th Pascal coefficient counts histories with exactly \(k\) FUCC insertions.

## 2. Partitions are the commutative/order-forgetting shadow

An unordered integer partition is obtained from a composition by forgetting the causal order of the SUCC runs.

For a partition

\[
\lambda=(\lambda_1,\ldots,\lambda_r)
\]

with multiplicity \(m_j\) of each repeated part size, the number of ordered compositions collapsing to that partition is

\[
\boxed{
\frac{r!}{\prod_j m_j!}.
}
\]

So ordinary partition theory is a symmetry quotient of the causal composition space.

This matches the broader research lesson: quotienting away order can erase the noncommutative/carry data.

## 3. A composition is a polynomial program

For

\[
\alpha=(a_0,a_1,\ldots,a_k)\models n,
\]

define its **FUCC/SUCC program polynomial**

\[
\boxed{
P_\alpha(x)
=
a_0x^k+a_1x^{k-1}+\cdots+a_{k-1}x+a_k.
}
\]

Then

\[
\boxed{
P_\alpha(1)=\sum_i a_i=n.
}
\]

Thus all composition-polynomials of \(n\) live in the augmentation fiber

\[
\varepsilon^{-1}(n),
\qquad
\varepsilon:\mathbb Z[x]\to\mathbb Z,
\quad
\varepsilon(P)=P(1).
\]

### Execution semantics

Let

\[
S(t)=t+1
\]

and let a FUCC-by-\(m\) operation be

\[
F_m(t)=mt.
\]

Starting from \(0\), execute

\[
S^{a_0},
F_m,
S^{a_1},
F_m,
\ldots,
F_m,
S^{a_k}.
\]

The output is exactly

\[
\boxed{
P_\alpha(m).
}
\]

Proof is the Horner recurrence:

\[
a_0
\mapsto
ma_0+a_1
\mapsto
m(ma_0+a_1)+a_2
\mapsto\cdots.
\]

So:

\[
\boxed{
\text{polynomial coefficient}
=
\text{SUCC run length},
}
\]

while

\[
\boxed{
\text{polynomial degree/depth}
=
\text{number of remaining FUCC operations}.
}
\]

The same causal history collapses to bare SUCC mass \(n\) when \(m=1\).

## 4. The augmentation ideal is literally the FUCC-detail channel

Since

\[
\ker\varepsilon=(x-1),
\]

every composition polynomial admits the unique decomposition

\[
\boxed{
P_\alpha(x)
=
n+(x-1)Q_\alpha(x).
}
\]

So \(n\) is the global coarse/SUCC channel, while everything depending on FUCC lies in the universal detail ideal generated by \(x-1\).

This is structurally compatible with the Round-004 local high-pass factor \(1-z\), but no RH implication is claimed here.

### Stronger exact statement: \(Q_\alpha\) stores the cut positions

Define the prefix sums

\[
c_j=a_0+a_1+\cdots+a_j,
\qquad
j=0,\ldots,k-1.
\]

These are exactly the gap positions after which FUCC was inserted in the original string of \(n\) SUCC pulses.

Then

\[
\boxed{
Q_\alpha(x)
=
\frac{P_\alpha(x)-n}{x-1}
=
c_0x^{k-1}+c_1x^{k-2}+\cdots+c_{k-1}.
}
\]

Hence the augmentation-detail polynomial is not merely an abstract quotient: its coefficients are exactly the causal FUCC cut locations.

### Example

For

\[
\alpha=(1,2,2)\models5,
\]

\[
P_\alpha(x)=x^2+2x+2.
\]

Its cut positions are

\[
c_0=1,\qquad c_1=3.
\]

And indeed

\[
P_\alpha(x)-5
=
(x-1)(x+3).
\]

So

\[
Q_\alpha(x)=x+3
\]

literally records the cuts \(1,3\).

## 5. Evaluating at radix \(m\) creates carry

Fix \(m\ge2\).

Write

\[
P_\alpha(x)=\sum_{j=0}^{k} b_j x^j
\]

in ascending-power notation, with \(b_j\ge0\).

Evaluating at \(m\) gives

\[
N=P_\alpha(m)=\sum_j b_jm^j.
\]

The coefficients \(b_j\) can be regarded as **pre-carry base-\(m\) digits**: unlike ordinary radix digits, they need not satisfy \(b_j<m\).

Normalize by ordinary carry propagation.

Set \(c_{-1}=0\). For \(j\ge0\), define digits \(d_j\in\{0,\ldots,m-1\}\) and carries \(c_j\ge0\) by

\[
\boxed{
b_j+c_{j-1}=d_j+mc_j.
}
\]

Continue with \(b_j=0\) above the degree until all carries vanish.

Then

\[
N=\sum_jd_jm^j
\]

is the standard base-\(m\) expansion.

Let

\[
s_m(N)=\sum_jd_j
\]

be the base-\(m\) digit sum.

Summing the carry equations gives the exact identity

\[
\boxed{
P_\alpha(1)-s_m(P_\alpha(m))
=
(m-1)\sum_{j\ge0}c_j.
}
\]

Since \(P_\alpha(1)=n\),

\[
\boxed{
n-s_m(P_\alpha(m))
=
(m-1)C_m(\alpha),
}
\]

where

\[
C_m(\alpha):=\sum_jc_j
\]

is the total number of carry units, counting multiplicity.

Thus the same composition polynomial simultaneously encodes:

- bare SUCC mass through \(P(1)\);
- FUCC evaluation through \(P(m)\);
- carry cost through the loss of digit sum.

For \(m=2\),

\[
\boxed{
C_2(\alpha)=n-s_2(P_\alpha(2)).
}
\]

## 6. Example: \(1+2+2\)

Take

\[
\alpha=(1,2,2),
\qquad
P(x)=x^2+2x+2.
\]

Bare SUCC:

\[
P(1)=5.
\]

FUCC-by-2 evaluation:

\[
P(2)=10.
\]

Raw coefficient state, from low to high powers, is

\[
(2,2,1).
\]

Binary carrying:

\[
(2,2,1)
\to
(0,3,1)
\to
(0,1,2)
\to
(0,1,0,1).
\]

There are \(3\) carry units.

Since

\[
10=1010_2,
\qquad
s_2(10)=2,
\]

the carry identity gives

\[
5-2=3.
\]

Exactly.

## 7. Fibonacci emerges naturally from the carry-free sector

A composition is carry-free under radix-\(m\) evaluation iff every coefficient/run length already satisfies

\[
1\le a_i\le m-1.
\]

Indeed, then no digit exceeds the radix and no carry is ever generated; conversely any part \(\ge m\) forces a carry.

Let

\[
A_m(n)
=
\#\{\alpha\models n:\text{ every part }\le m-1\}.
\]

Then

\[
\boxed{
A_m(n)
=
\sum_{j=1}^{m-1}A_m(n-j),
}
\]

with

\[
A_m(0)=1,
\qquad
A_m(n)=0\text{ for }n<0.
\]

So the carry-free histories form the \((m-1)\)-step Fibonacci family.

In particular for \(m=3\), allowed parts are only \(1\) and \(2\), giving

\[
\boxed{
A_3(n)=F_{n+1}
}
\]

for the convention \(F_1=F_2=1\).

Thus the earlier intuition that Fibonacci might appear in the primitive recursive machine is correct in a precise but specific sense:

> **Fibonacci counts the FUCC/SUCC histories that require no carry when the FUCC multiplier is \(3\).**

For \(m=4\), one gets tribonacci-type counting; in general the order of the recurrence is \(m-1\).

## 8. The affine semigroup is already present

As maps of \(\mathbb N_0\),

\[
S(t)=t+1,
\qquad
F_m(t)=mt.
\]

They obey

\[
\boxed{
F_mS=S^mF_m.
}
\]

Every composition polynomial therefore represents a concrete alternating word in the same SUCC/FUCC affine semigroup that survived Round004.

The composition-polynomial model is a low-level program syntax for that semigroup.

This makes it a natural pre-spectral state space for Round005's carry/refinement investigation.

## 9. What is and is not prime-specific

Everything above is true for every positive integer \(n\).

Therefore:

\[
2^{n-1},
\quad
P_\alpha(1)=n,
\quad
P-n\in(x-1),
\quad
\text{and the carry identity}
\]

do **not** distinguish primes.

For a prime \(p\), define the composition fiber

\[
\mathcal C(p)
=
\{\alpha:\alpha\models p\}.
\]

The prime-specific research question is not the size of this fiber. It is how the self-sieving carry network acts on the FUCC evaluations

\[
P_\alpha(m),
\qquad
m=2,3,5,\ldots,
\]

and on their carry profiles.

Potential observables include:

\[
C_m(\alpha)
=
\frac{p-s_m(P_\alpha(m))}{m-1},
\]

the complete carry vector

\[
(c_0,c_1,\ldots),
\]

and residue/clock responses of \(P_\alpha(m)\).

These are proposed probes, not RH claims.
