# 2. Exact support theorem for rational-affine words

Let

\[
F_j(x)=\alpha_jx+\beta_j
\]

be the \(j\)-th prefix.

Choose a common denominator \(q_j>0\) and integers \(u_j,v_j\) such that

\[
F_j(x)=\frac{u_jx+v_j}{q_j}.
\]

Then

\[
F_j(n)\in\mathbb Z
\]

\[
u_jn+v_j\equiv0\pmod{q_j}.
\]

Let

\[
g_j=\gcd(u_j,q_j).
\]

This congruence is solvable iff

\[
g_j\mid v_j.
\]

When solvable, divide by \(g_j\). Since

\[
\gcd(u_j/g_j,q_j/g_j)=1,
\]

the condition reduces to one residue class

\[
n\equiv r_j\pmod{m_j},
\qquad
m_j=q_j/g_j.
\]

The full path is integral exactly when all prefix congruences hold:

\[
n\equiv r_j\pmod{m_j}
\qquad
(1\le j\le\ell).
\]

By generalized CRT, their intersection is either empty or one class modulo

\[
\boxed{
M_\gamma
=
\operatorname{lcm}(m_1,\ldots,m_\ell).
}
\]

Hence

\[
\boxed{
\operatorname{Supp}_{\mathbb Z}(\gamma)
=
\varnothing
\quad\text{or}\quad
r_\gamma+M_\gamma\mathbb Z.
}
\]

This is a complete finite characterization for the integrality part of a rational-affine path.
